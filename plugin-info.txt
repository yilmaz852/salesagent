A comprehensive sales dashboard for WooCommerce with detailed reporting, commission tracking, and refund calculations.

== Description ==

WooCommerce Sales Dashboard provides a powerful admin interface for tracking sales performance, calculating commissions, and analyzing order data with advanced filtering options.

**Key Features:**

* Filter reports by sales agent
* Date range selection
* Exclude specific order statuses
* Calculate gross totals and refunds
* Track net subtotals after refunds
* Automatic commission calculation (3%)
* Visual metric widgets
* Detailed order-by-order breakdown

**Perfect For:**

* Sales managers tracking team performance
* Business owners monitoring revenue
* Accountants calculating commissions
* Anyone needing detailed WooCommerce sales reports

== Installation ==

1. Upload `woocommerce-sales-dashboard.php` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Ensure WooCommerce is active
4. Navigate to 'Sales Dashboard' in the admin menu

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes, WooCommerce must be installed and active for this plugin to work.

= What is the 'sales_agent' role? =

This is a custom user role that should be assigned to your sales team members. The plugin filters orders based on the 'wcb2bsa_sales_agent' meta key.

= How is commission calculated? =

Commission is calculated as 3% of the Net Item Subtotal (Item Subtotal minus Refund Subtotal).

= Can I exclude certain order statuses? =

Yes, you can select which order statuses to exclude from the report using checkboxes in the form.

= What date range is used by default? =

By default, the report shows data from the first day of the current month to today.
